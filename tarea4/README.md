# Tarea 4: Consultas Avanzadas en SQL (MySQL)

* <u>Módulo</u>: Bases de Datos (DAW/DAM)
* <u>Unidad de Trabajo</u>: UT04. Realización de consultas.
* <u>Curso Académico</u>: 2022/2023 (Referencia)

## 📝 Descripción del Proyecto

Este proyecto corresponde a la Tarea 4 del módulo de Bases de Datos y tiene como objetivo principal consolidar el uso del lenguaje SQL (Structured Query Language), centrándose en la recuperación avanzada de datos mediante consultas sobre una base de datos predefinida de Instrumentos Musicales.

La tarea se estructura en torno a una serie de actividades progresivas que cubren desde consultas básicas con filtros hasta operaciones más complejas como subconsultas y agrupaciones.

## 🎯 Objetivos de Aprendizaje

Los principales resultados de aprendizaje trabajados en esta tarea son:

* <u>RA3</u>: Aplicar el lenguaje de manipulación de datos para la gestión de la información en una base de datos relacional.
* <u>Dominio de SQL</u>: Reforzar el conocimiento y la aplicación de las cláusulas esenciales de SQL (SELECT, FROM, WHERE, JOIN, GROUP BY, HAVING).

## ⚙️ Estructura de la Tarea y Consultas Clave

La tarea se divide en 5 actividades, cada una enfocada en un aspecto diferente de las consultas SQL, que se implementan y documentan.

| Actividad | Tema Principal | Tipo de Consultas | Criterios Específicos |
| :---: |  :---: | :---: | :---: |
| Actividad 1 | Consultas Simples | Filtros, proyecciones. | Uso de SELECT y WHERE. |
| Actividad 2 | Consultas de Ordenación | Ordenación de resultados. | Uso de ORDER BY y LIMIT (si aplica). |
| Actividad 3 | Consultas con Uniones (JOIN) | Recuperación de datos de múltiples tablas. | Uso de INNER JOIN, LEFT JOIN, etc. |
| Actividad 4 | Consultas Resumen (Agregación) | Agrupación y funciones agregadas. | Uso de GROUP BY, HAVING, COUNT, SUM, AVG, MAX, MIN. |
| Actividad 5 | Subconsultas | Consultas anidadas y correlacionadas. |Uso de subconsultas en SELECT, FROM y WHERE. |

## 🛠️ Tecnologías Utilizadas

* <u>Sistema de Gestión de Bases de Datos (SGBD)</u>: MySQL (o cualquier otro compatible con SQL estándar).
* <u>Lenguaje</u>: SQL.

## 📂 Contenido del Repositorio

El repositorio debe incluir:

    1. SQL/: Directorio conteniendo el fichero o ficheros con las sentencias SQL para crear la base de datos (DDL), insertar datos (DML) y todas las consultas realizadas en las 5 actividades.
    2. Documentacion/: Archivo (o archivos) con las capturas de pantalla de la ejecución de las consultas y la verificación de los resultados, tal como se requiere en el enunciado.
    3. README.md (Este archivo).

Este proyecto demuestra la capacidad para escribir sentencias SQL eficientes y cumplir con los requisitos específicos de recuperación de información de negocio complejos.

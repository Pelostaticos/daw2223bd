# Resumen del Módulo de Bases de Datos (DAW)

Este repositorio documenta las soluciones desarrolladas para las tareas del módulo de Bases de Datos del ciclo formativo de Desarrollo de Aplicaciones Web (DAW) del curso 2022/2023. Dichas tareas corresponden con las unidades 4 a 7.

![IMagen destacable del repositorio de Base de Datos](https://bitgarcia.es/wp-content/uploads/2025/12/destacable-daw2223bd.png)

## 📌 Introducción y Contexto

Debido a mi incorporación al ciclo formativo a tan solo tres meses de su finalización, por cuestiones laborales y personales, no fue posible entregar las tareas correspondientes a las Unidades 1, 2 y 3 (Modelado, Diseño Relacional, DDL/DCL).
A pesar de la incorporación tardía, este repositorio contiene el trabajo realizado y entregado a partir de la Unidad 4, demostrando la asimilación de los contenidos fundamentales de SQL, programación procedimental y Bases de Datos Objeto-Relacionales.

## 📚 Resumen de Tareas Desarrolladas

A continuación, se presenta un resumen de las tareas realizadas y los principales objetivos de cada una, sirviendo como guía del contenido de los directorios de este proyecto:

|  Tarea  |                    Título de la Tarea                     |                      Unidad                      |                                                                                                               Objetivo Principal                                                                                                               |
| :-----: | :-------------------------------------------------------: | :----------------------------------------------: | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------: |
| Tarea 4 |           Base de datos instrumentos musicales            |         UT04: Realización de consultas.          |                             Dominio del lenguaje DML: Creación de consultas complejas (SELECT) utilizando JOINs, agrupaciones (GROUP BY, HAVING), funciones de agregado y subconsultas correlacionadas y anidadas.                             |
| Tarea 5 |              Base de datos grupos de trabajo              |           UT05: Tratamiento de datos.            |            Gestión avanzada de datos (DML): Aplicación de sentencias INSERT, UPDATE y DELETE. Énfasis en el manejo de transacciones, bloqueos de tablas y políticas de concurrencia para mantener la integridad de la información.             |
| Tarea 6 | Programación en la Base de datos "Actividades deportivas" |      UT06: Programación de bases de datos.       |              Introducción a la Programación Procedimental (PL/SQL o T-SQL): Creación y prueba de funciones, procedimientos almacenados y disparadores (triggers), incluyendo lógica de control de flujo y manejo de excepciones.               |
| Tarea 7 |                    Jugando con cartas                     | UT07: Uso de Bases de Datos Objeto-Relacionales. | Implementación de Bases de Datos Objeto-Relacionales (BDOR): Creación de tipos de objetos complejos, tipos de colección (VARRAYs/Tablas Anidadas) y tablas de objetos para modelar un juego de cartas, manipulando la persistencia de objetos. |

## 🔑 Tecnologías Clave

* <u>SGBD</u>: MySQL / Oracle Database Express Edition (según la tarea).
* <u>Lenguajes</u>: SQL (DDL, DML, DCL), PL/SQL.
* <u>Conceptos</u>: Modelo Entidad-Relación, Normalización, Consultas Avanzadas, Transacciones, Programación Procedimental, Bases de Datos Objeto-Relacionales.

## 🏁 Conclusión

Este conjunto de tareas representa el esfuerzo intensivo por completar los módulos de Bases de Datos avanzados en un corto período. El trabajo cubre desde la manipulación transaccional de datos hasta la implementación de lógica de negocio compleja dentro del propio SGBD y el manejo de estructuras de datos orientadas a objetos.
